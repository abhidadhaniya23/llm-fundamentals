Four ways context breaks

Curate, don’t dump — the model can’t tell what matters to you.

Clash
Two sources quietly contradict each other; it trusts one. Fixed by evidence in the pile — dates, versions, a second document — not by asking.
Confusion
Noise nudges the output. A runbook pasted into the prompt gets absorbed into the answer; the same runbook read from a folder gets ignored.
Distraction
Trailing context that isn’t about this task bleeds in. Fix: new topic, new chat.
Poisoning
A wrong fact planted early gets trusted later, turn after turn. Fix: new chat, or name the stale source out of scope.
