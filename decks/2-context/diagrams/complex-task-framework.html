When one ask isn’t enough

A complex task isn’t a bigger prompt — it’s steps, each with the context it needs.

Plan
State the task, take the plan, critique it, then say go. A checkpoint you can read — cheaper to fix than the output.
Write
Save the plan and each step’s output to a file; the file is context that survives the chat.
Isolate
Separate tasks get separate threads or sub-agents.
Compress
A long history gets summarised; in Devin that’s /compact.
